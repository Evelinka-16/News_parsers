# University News Monitoring Service

Сервис для автоматического мониторинга и сбора новостей с сайтов вузов (ВШЭ, РЭУ, РТУ МИРЭА, КФУ) в единую базу SQLite с последующим формированием персональных рассылок по интересам пользователей.

---

## Стек технологий
* **Python 3.13+**
* **Менеджер пакетов:** `uv`
* **Парсинг:** `BeautifulSoup4`, `requests`
* **Обработка данных:** `pandas`
* **База данных:** `SQLite3`

---

```text
├── pyproject.toml           # Зависимости проекта
├── uv.lock                  # Зафиксированные версии библиотек
└── README.md
```

## Как это работает

1. `main.py` при запуске проверяет и создаёт (если их ещё нет) таблицы в `news.db` (новости, категории, вузы) и в `users.db` (пользователи и их подписки на категории).
2. Автоматически подхватывает все модули вида `parser_*.py` из папки `parsers/` — у каждого из них должна быть функция `parse()` без аргументов.
3. По кругу, с интервалом из `config.json` (`interval_minutes`), запускает каждый парсер: он собирает новости со своего сайта вуза и сохраняет новые записи в `news.db`, не создавая дублей по ссылке (`link`).
4. После каждого цикла собирает персональную рассылку — для каждого пользователя подборку новостей по тем категориям, на которые он подписан, — и сохраняет её в `send_list.txt`.

## Запуск

```bash
uv sync
uv run main.py
```

или без `uv`:

```bash
pip install -r requirements.txt
python main.py
```

Настройки (интервал опроса, имена файлов БД, папка с парсерами) — в `config.json`.

---

## Добавление нового парсера

Чтобы подключить ещё один вуз, достаточно положить в `parsers/` файл `parser_<название>.py` с функцией `parse()` без аргументов — `main.py` подхватит его автоматически при следующем запуске.
